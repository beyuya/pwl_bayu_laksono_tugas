# 📚 Sistem Informasi Perpustakaan

Sistem Informasi Perpustakaan merupakan aplikasi web sederhana yang dibuat menggunakan PHP dan MySQL untuk membantu pengelolaan data buku perpustakaan.

Aplikasi ini dibuat sebagai tugas mata kuliah Pemrograman Web Lanjut.

## ✨ Fitur Aplikasi

    🌐 Halaman Publik
      - Halaman utama perpustakaan
      - Menampilkan koleksi buku
      - Pencarian buku berdasarkan judul atau pengarang
      - Informasi stok buku

    🔐 Admin
      - Login administrator
      - Dashboard admin
      - Melihat data buku
      - Menambahkan data buku
      - Mengubah data buku
      - Menghapus data buku
      - Logout

    📚 CRUD Data Buku
      - Create – Menambahkan data buku
      - Read – Menampilkan data buku
      - Update – Mengubah data buku
      - Delete – Menghapus data buku
